# Tidya Talks

Presentasjoner og foredrag fra Tidya sine konsulenter. Statisk, uten byggesteg.

**Live:** https://tidya-no.github.io/tidya-talks/

## Innhold

| Fil | Formål |
|---|---|
| `index.html` | Forsiden med oversikt over foredragene |
| `bekjentskap-med-kotlin.html` | Foredraget «Bekjentskap med Kotlin — en Javaveterans reisebrev» (reveal.js) |
| `CLAUDE.md` | Beskrivelse av Kotlin-foredraget for AI-assistenter |
| `talks.css` | Layout for forsiden |
| `tokens.css`, `components.css`, `fonts/`, `brand/` | Kopiert fra [tidya-design-guide](https://github.com/Tidya-no/tidya-design-guide). Skal ikke endres her |

Forsiden følger Tidya designsystem. Oppdater designfilene ved å kopiere dem på nytt fra guiden.

## Kjøre lokalt

Åpne `index.html` i nettleseren, eller kjør en enkel filserver:

```sh
npx http-server . -p 8080
```
